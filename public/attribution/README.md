# Google Maps attribution

`google-maps.svg` is the unmodified DarkGray SVG from Google's official
[Google Maps Attribution Assets](https://developers.google.com/static/maps/documentation/images/Google_Maps_Attribution_Assets.zip).

It is a Google trademark asset, used only for provider attribution under the
[Places API policies](https://developers.google.com/maps/documentation/places/web-service/policies).
The application's MIT license does not grant rights to Google's trademarks.

Render it at 16–19 CSS pixels high, preserve its aspect ratio, and keep at least
10 pixels of whitespace to the left, right and top and 5 pixels below.
